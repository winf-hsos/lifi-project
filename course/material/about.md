# About

Online: <https://docs.lifi-project.de/about.html>

This website accompanies the project course in the module Digitization and Programming at **Hochschule Osnabrück** (Osnabrück University of Applied Sciences). In it you build a device that transmits data with visible light, and along the way you learn how computers represent, store, transfer and process information, and how to cut a problem into steps you can test.
